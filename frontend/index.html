Recipient mode

        
Encrypt: needs at least one recipient or a recipients file. A recipient is an age public key (age1..., post-quantum age1pq1...) or an SSH public key (ssh-ed25519 ..., ssh-rsa ...). Everyone listed can decrypt the file. Post-quantum and classic keys can't be mixed in one file.

        
Decrypt: needs at least one identity file holding secret keys (AGE-SECRET-KEY-1...) or an SSH private key. Unused ones are ignored.

        
Generate new key pair creates an identity file and adds it here together with its public key. Keep that file secret and backed up: without it, files encrypted to its public key cannot be decrypted.

        
Not supported yet: age plugins, passphrase-protected identity files and passphrase-protected SSH keys.
